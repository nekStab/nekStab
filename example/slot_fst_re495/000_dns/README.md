# Slot jet with free-stream turbulence (FST) — DNS at Re=495

## Physics
Slot jet at Re = 495 forced by a synthetic free-stream turbulence (FST) inflow.
Direct numerical simulation from a uniform initial condition.

## nekStab Mode
- `userParam01 = 0` — DNS
- `viscosity = -495.0` — Re = 495

## Initial / boundary conditions
- `startFrom = 0` — uniform IC.
- `FST_data/FST_inflow.bin` — the synthetic FST inflow (shipped). Generated by
  the nekStab FST module; **regenerate with `OMP_NUM_THREADS=1`** to avoid BLAS
  thread oversubscription. `SPGslot0.f00001` is the sponge field.

## Run
```bash
mks slot
sbatch run.local.slurm     # 8 ranks
```

## Reference (ref/)
Figure/IC reference — the shipped `slot.his` is degenerate, so `reference.json`
asserts no numeric scalar. Compare a fresh run's spectra visually against:
- `ref/fft.png`, `ref/signal.png`, `ref/phase.png` (probe time-series spectra)
- `ref/snapshot.png` (flow field)
