# Slot jet with free-stream turbulence (FST) — DNS at Re=495

## Physics
Slot jet at Re = 495 forced by a synthetic free-stream turbulence (FST) inflow.
Direct numerical simulation from a uniform initial condition.

## nekStab Mode
- `userParam01 = 0` — DNS
- `viscosity = -495.0` — Re = 495

## Initial / boundary conditions
- `startFrom = 0` — uniform IC.
- `FST_data/FST_inflow.bin` — the synthetic FST inflow (shipped). Generated by
  the nekStab FST module; **regenerate with `OMP_NUM_THREADS=1`** to avoid BLAS
  thread oversubscription. `SPGslot0.f00001` is the sponge field.

## Run
```bash
mks slot
sbatch run.local.slurm     # 16 ranks
```

## Reference (ref/)
`reference.json` holds statistics of the t = 100 field `slot0.f00001`: the time stamp, the maxima, minima and
L2 norms (sum over all nodes of the squares, square root) of vx and vy. They are regression values of this
repository, not literature values. The FST inflow is the shipped binary, so the run is deterministic: the probe
histories of a 16 and a 32 rank run agree to the seventh digit. Tolerance 1e-3 (relative). Verify with
`scripts/check_against_ref.py example/slot_fst_re495/000_dns`.

The figures `ref/signal.png`, `ref/fft.png` and `ref/phase.png` show the probe at (x, y) = (8.3333, 1.3333), the
first of the three in `slot.his` (the file holds one row per probe at each step, so `plot.py` takes every third row).
The signal is the response to the FST: it has no single frequency, and its spectrum has the maximum at f = 0.047 and
falls by about six decades up to f = 0.5. `ref/snapshot.png` shows |u| at t = 100. Run on 16 ranks of c8: 246 s.
