# Thermosyphon, Ra = 500

The buoyancy-driven annular thermosyphon just above the critical Rayleigh number: DNS, the
Newton steady state and direct stability.

Stage rationale: see [EXAMPLES.md](../../EXAMPLES.md).

## Case note

This case is the annular-thermosyphon scalar-convection example. It exercises
base-flow and stability workflows on a buoyancy-driven flow where pitchfork and
Hopf mechanisms can be studied in a compact two-dimensional geometry. Thesis
source: chapter 2, `sec:ex:thermo`, including the pitchfork and Hopf
bifurcation subsections; AMR_Krylov_V5 Main `S5_examples.tex`,
`sec:ex:thermo`.
